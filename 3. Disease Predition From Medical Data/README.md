# ❤️ Heart Disease Prediction Flask Application

A **Heart Disease Prediction** web application developed during my **Machine Learning Internship at CodeAlpha**.

## 📌 Overview

This project uses **Machine Learning** to predict the likelihood of heart disease based on medical data provided by the user. The model is integrated into a user-friendly **Flask web application**.

## 🌟 Features

* Flask-based web application
* User-friendly prediction form
* Machine learning model for prediction
* Results page
* Responsive HTML/CSS interface

## 🛠️ Technologies Used

* Python
* Flask
* Scikit-learn
* Pandas
* NumPy
* HTML
* CSS

## 📁 Project Structure

```text
├── app/
│   └── app.py

└── README.md
```

## 🚀 How to Run

```bash
pip install -r requirements.txt
python app.py
```

Then open:

```text
http://127.0.0.1:5000/
```
