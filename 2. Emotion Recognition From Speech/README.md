# Emotion Recognition from Speech 🎤

A **Speech Emotion Recognition** project developed during my **Machine Learning Internship at CodeAlpha** using an **LSTM deep learning model**.

## 📌 Overview

The model analyzes speech audio and predicts emotions such as **fear, sadness, and others** using extracted audio features.

## 🛠️ Technologies

* Python
* TensorFlow / Keras
* Librosa
* NumPy
* Pandas
* Scikit-learn
* Jupyter Notebook

## 🔍 Project Workflow

1. Data Collection
2. Audio Preprocessing
3. Data Augmentation
4. Feature Extraction
5. LSTM Model Training
6. Model Evaluation
7. Model Saving
8. Web App Deployment

## 🚀 How to Run

```bash
git clone https://github.com/yourusername/emotion-recognition-speech.git
cd emotion-recognition-speech
pip install -r requirements.txt
python app.py
```

## 📁 Main Components

* `app.py` — Web application
* `Jupyter Notebook` — Experiments and analysis
* `LSTM model` — Trained model
* `test audio files` — Sample audio for prediction
* `requirements.txt` — Required libraries
